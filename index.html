What If Studio

A privately operated production tool for the What If Studio YouTube channel. It helps the channel owner create science explainers, review their quality, upload videos and manage a publishing calendar.

Why it connects to Google

The owner signs in with Google to authorize access to their own YouTube channel. The application uses YouTube APIs to check channel identity, upload and manage videos, set native publication schedules, and read channel performance reports. This is an owner-operated tool, not a public account-management service.

How it operates

Production and local records run on the owner's computer. Previously scheduled videos can be published by YouTube while that computer is off. Production uses OpenAI for writing and review and ElevenLabs for narration. Uploading a private test and enabling public scheduling are separate steps.
